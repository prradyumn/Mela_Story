Voice Studio

Generates every game voice line (Level 1 + Level 2) with Gemini TTS and saves them into assets/game/vo. Your API key stays in this browser tab only — it is never saved to a file.

Choose the game folder first (Chrome / Edge). If your browser can’t pick folders, the lines are kept here and you can download a ZIP — unzip it into Mela_Story/assets/game/vo.
